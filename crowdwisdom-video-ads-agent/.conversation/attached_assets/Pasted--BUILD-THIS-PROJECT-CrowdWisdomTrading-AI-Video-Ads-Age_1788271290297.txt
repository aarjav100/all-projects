# BUILD THIS PROJECT: CrowdWisdomTrading AI Video Ads Agent

You are an expert Python engineer, AI-agent architect, performance marketer, creative director, and video-generation engineer.

Build a complete production-quality Python project for the **CrowdWisdomTrading Video Ads Agent internship assessment**.

The goal is NOT to generate text advertisements.

The goal is to build an autonomous **AI marketing-agent pipeline that researches winning ads, identifies marketing patterns, researches current trader pain points, creates high-quality video-ad storyboards, and renders actual 30–60 second video advertisements.**

The final result must demonstrate both:

1. Strong Python / AI-agent engineering
2. Strong marketing creativity and video-ad thinking

The generated ads should make the evaluator think:

> "WOW — this is an actual creative advertising system, not just an LLM wrapper."

---

# 1. CORE PROJECT OBJECTIVE

Build a multi-agent system for:

https://www.crowdwisdomtrading.com/

The system should automatically:

1. Research successful competitor/trading ads
2. Collect recent ads from the last 30 days
3. Analyze their hooks, pain points, ICPs, concepts, structures and CTAs
4. Research current trader pain points and market conversations
5. Analyze CrowdWisdomTrading's unique/proprietary data
6. Generate 3 distinct video-ad concepts
7. Generate detailed video storyboards
8. Generate voiceover/dialogue/captions/visual directions
9. Generate the actual 30–60 second video
10. Save all research, reasoning outputs, scripts and metadata as JSON
11. Provide a simple interface to run the complete pipeline
12. Produce a final MP4 that can be shown to the internship evaluator
